# Yahtzee para Dos Jugadores en Python aplicando el metodo de montecarlo

Un juego clásico de Yahtzee desarrollado con Python y Tkinter para dos jugadores locales.

## Requisitos
- Python 3.8 o superior instalado.

## Cómo ejecutar el juego
1. Clona este repositorio o descarga los archivos.
2. Abre tu terminal en la carpeta del proyecto y ejecuta:
   ```bash
   python src/yahtzee.py
